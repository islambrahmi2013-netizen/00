# سباق النخبة 🏁

لعبة سباق سيارات ثنائية الأبعاد تعمل مباشرة في المتصفح، مبنية بـHTML وCSS وJavaScript فقط.

## اللعب

- تحرك بالأسهم **يمين / يسار** أو بمفاتيح **A / D**.
- على الهاتف استخدم الأزرار الدائرية أسفل الشاشة.
- تجنب السيارات المنافسة.
- اجمع العملات لزيادة النقاط.
- تزيد سرعة السباق تدريجيًا مع تقدّم المسافة.

## التشغيل

افتح `index.html` مباشرة، أو شغّل خادمًا بسيطًا:

```bash
python3 -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

يمكن نشرها مباشرة عبر GitHub Pages من إعدادات المستودع.
